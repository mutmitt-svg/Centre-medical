Version compilée de l'application de gestion du centre de santé.

Ce dossier contient uniquement du HTML, du CSS et du JavaScript déjà compilés.
Il se sert par n'importe quel serveur web, sans Node.js et sans compilation.

Démarrage immédiat, au choix :

  python3 -m http.server 8080        puis ouvrir http://localhost:8080
  npx serve .                        puis ouvrir l'adresse affichée

Publication : copiez tout le contenu de ce dossier à la racine du site
(Nginx, Apache, Vercel, Netlify, Cloudflare Pages, GitHub Pages, partage réseau).

N'ouvrez pas index.html par un double-clic : les modules JavaScript exigent le
protocole http, pas file://.

Configuration de la base : cette version est compilée sans variables
d'environnement, elle démarre donc en mode découverte avec le jeu de
démonstration. Pour la relier à Supabase, renseignez .env.local à la racine du
projet puis relancez npm run build ; le nouveau contenu de dist/ remplace ce
dossier.
