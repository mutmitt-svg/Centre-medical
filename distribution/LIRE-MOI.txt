Version compilée de l'application de gestion du centre de santé.

Ce dossier contient uniquement du HTML, du CSS et du JavaScript déjà compilés,
avec des chemins relatifs : il fonctionne à la racine d'un domaine comme dans un
sous-répertoire, par exemple https://compte.github.io/centre-sante-app/.

Essai local immédiat, sans Node.js :

  python3 -m http.server 8080        puis ouvrir http://localhost:8080
  npx serve .                        puis ouvrir l'adresse affichée

Publication sur GitHub Pages, deux méthodes décrites dans le README du projet :

  1. automatique, recommandée : le flux .github/workflows/publier-pages.yml
     compile et publie à chaque poussée sur la branche principale ;
  2. manuelle : copier le contenu de ce dossier sur une branche gh-pages.

Le fichier .nojekyll est présent et nécessaire : sans lui, GitHub Pages ignore
certains fichiers générés.

N'ouvrez pas index.html par un double-clic : les modules JavaScript exigent le
protocole http, pas file://.

Cette version est compilée sans variables d'environnement, elle démarre donc en
mode découverte avec le jeu de démonstration. Pour la relier à Supabase,
renseignez .env.local puis relancez npm run build.
